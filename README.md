# DAA_Lab_Practice
# Design and Analysis of Algorithms (DAA)

A collection of **Design and Analysis of Algorithms (DAA)** lab programs implemented in **C**, covering fundamental algorithmic techniques, problem-solving approaches, and their practical implementations.

This repository contains academic lab assignments, algorithm implementations, and additional coding practice problems.

## 📚 Repository Contents

### 1. Basic Algorithms
- Finding Second Minimum and Maximum
- Prefix Sum
- Finding Duplicates
- Array Rotation

### 2. Number Systems and Mathematics
- Decimal to Binary Conversion
- Greatest Common Divisor (GCD)

### 3. Sorting Algorithms
- Merge Sort
- Quick Sort
- Heap Sort
- Insertion Sort

### 4. Greedy Algorithms
- Fractional Knapsack
- Huffman Coding
- Greedy Reduction

### 5. Graph Algorithms
- Prim's Minimum Spanning Tree
- Kruskal's Minimum Spanning Tree
- Dijkstra's Shortest Path Algorithm
- Breadth-First Search (BFS)
- One-Way Connected Graph

### 6. Dynamic Programming
- Matrix Chain Multiplication
- Longest Common Subsequence (LCS)
- Floyd-Warshall Algorithm

### 7. Advanced Algorithms
- Randomized Quick Sort
- Binary Search (Leftmost Occurrence)
- Fit String
- Binary Counter Reset

### 8. Additional Practice
- Insertion Sort
- BFS
- Binary Search
- LeetCode problem-solving practice

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd daa_lab
   ```

3. Compile any C program:

   ```bash
   gcc filename.c -o output
   ```

4. Execute the compiled program:

   ```bash
   ./output
   ```

   On Windows:

   ```bash
   output.exe
   ```
